Publishing

This machine does not post anywhere, and there is no account to connect. What the pipeline produces instead is an export pack beside every clip: title, caption trimmed to each platform's real limit, hashtags, chapters and a thumbnail — ready to paste.
Why there is no Connect button

A scheduler here would need stored platform credentials and outbound posting rights. Both break the one guarantee this tool makes. The export pack gets you to the same place with a copy and a paste, and the draft is auditable before it goes out.
