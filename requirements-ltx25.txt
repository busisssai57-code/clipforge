# NOT optional, despite reading like it. The image-to-video path
# re-compresses its conditioning frame through H.264 -- the model was
# trained on compressed video and a pristine frame is off-distribution --
# and without PyAV the pipeline RAISES. Measured 2026-09-05: a missing `av`
# turned the first chained shot of a batch into "no generation provider
# could produce this shot".
#
# The worker degrades to image_crf=0 and logs `i2v_no_pyav` rather than
# losing the beat, so a venv rebuilt without this line still renders -- it
# just quietly stops matching the model's training distribution, which is
# exactly the kind of silent downgrade this file exists to prevent.
